# 示例项目

这是一个示例项目文档，用于展示 `projects` collection 的目录组织方式。

在 `docs/projects/example/` 下创建更多 markdown 即可扩展该项目的文档。

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/kiwi-embedded/example.git
cd example

# 安装依赖
pnpm install

# 跑起来
pnpm dev
```

## 目录结构

```
example/
├── README.md         # 当前页面
├── getting-started.md
└── api/
    └── reference.md
```
